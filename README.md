# Action Analyzer: Motion Tracking and Pose Detection

**Action Analyzer** is a lightweight real-time motion tracking tool built with OpenCV and MediaPipe.  
It processes video input to detect human poses and dynamically render stick figure animations of detected movements.

---

## ✨ Features

- Real-time pose detection using MediaPipe Pose.  
- Dynamic stick figure visualization over video frames.  
- Lightweight and optimized frame resizing (640x480).  
- Simple and clean code structure for easy future extension.  
- User-prompted video input for flexible testing.

---

## 🛠️ Tech Stack

- **Python**  
- **OpenCV**  
- **MediaPipe**

## 🚀 How It Works

### 🔧 Installation & Setup

1. **Clone the repository** (or download the ZIP):

You have multiple options to clone the repository depending on your workflow:

#### 🔹 Option 1: Using the Terminal

```bash
git clone https://github.com/SHAIMOOM251283/Action-Analyzer-Motion-Tracking-and-Pose-Detection.git
cd Action-Analyzer-Motion-Tracking-and-Pose-Detection
```

#### 🔹 Option 2: Using VS Code's Git Integration

- Open **Visual Studio Code**.  
- Press `Ctrl + Shift + P` (or `Cmd + Shift + P` on macOS) to open the Command Palette.  
- Type and select **Git: Clone**.  
- Paste the repository URL:

  ```
  https://github.com/SHAIMOOM251283/Action-Analyzer-Motion-Tracking-and-Pose-Detection.git
  ```

- Choose a local folder and click **Open** to load the repo in VS Code.

#### 🔹 Option 3: Using VS Code's Integrated Terminal

- Open **VS Code**.  
- Press `` Ctrl + ` `` or go to **Terminal > New Terminal**.  
- Run:

  ```bash
  git clone https://github.com/SHAIMOOM251283/Action-Analyzer-Motion-Tracking-and-Pose-Detection.git
  cd Action-Analyzer-Motion-Tracking-and-Pose-Detection
  ```

> 💡 Or simply download the ZIP and extract it to a local folder.

---

2. **Set up a virtual environment** (recommended):

Make sure you have **Python 3.8+** installed.

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS/Linux
python3 -m venv venv
source venv/bin/activate
```

---

3. **Install required dependencies**:

```bash
pip install opencv-python mediapipe
```

> ✅ That's all you need to run the project!

---

### ▶️ Running the Program

1. **Launch the script**:

   ```bash
   python action_analyzer.py
   ```

2. **Enter the path to your video file** when prompted (e.g., `figure_skating.mp4`).

3. **Watch stick figure motion tracking in action!**  
   The program detects human pose landmarks in real-time and overlays a dynamic stick figure on each frame.

4. **Press `'q'` anytime to exit** the viewer window.
